### How to read this

- **solid** = enough games to act on. **thin** = directional. **noise** = do not act on it, however good the number looks.
- Only *stats-eligible* games count: incomplete practice duel sets and one-off clan battles are excluded (see `is_stats_eligible` / `is_real_practice_session`).
- Pairs use only **complete** duels with a certain start.
- Win conditions come from `classify_deck()`, which is community knowledge rather than an API field — a deck with no recognised win condition is skipped.
